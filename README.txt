# Visual Information Analysis: workshop materials

Python notebooks for the weekly workshops of Visual Information Analysis, a final-year BSc module at the University of Salford. I support these workshops as a Teaching Assistant.

## What is inside
- Image basics with OpenCV and Pillow
- Filtering in the spatial and frequency domains
- Segmentation with thresholding (Otsu) and morphology
- Feature extraction (PCA, LBP, SIFT)
- Side-by-side method comparisons, so students choose and justify their own pipeline

## How to use
Open a notebook in Jupyter or Google Colab and run the cells from the top.
